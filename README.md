# LWC

Salesforce DX project (Lightning Web Components + Apex) for this org's
customizations.

## Salesforce Knowledge on the Case Detail Page

This repo includes a custom "Suggested Knowledge Articles" component for the
Case Lightning Record Page (SOSL-matched published articles, with one-click
attach to the case). See
[`docs/knowledge-base-case-integration.md`](docs/knowledge-base-case-integration.md)
for the full technical approach, including the declarative Knowledge setup
steps, security model, and deployment instructions.
